
## 这项功能解决什么问题

Sensor Map 用于根据项目实际使用的传感器和校准范围，生成一份精简后的传感器地图 Excel。

原始模板包含多种传感器、不同安装位置和多类校准项。用户只需提供一段传感器配置，例如 `3*PCS+UFSXY+2*PAS`，系统就会判断哪些章节需要保留、哪些行不适用，以及哪些校准列可以删除。最终输出的 Excel 只保留当前项目需要的信息。

生成的文件名类似：

```text
BX11_Sensor_Map_20260817.xlsx
```

## 如何调用

接口位于 [PUMA_Server/api/report.py](../PUMA_Server/api/report.py)，路由为：

```text
POST /app-puma/report/generateSensorMap
```

接口接受 JSON 请求，也兼容表单请求。常用字段如下：

```json
{
  "peripheralSensorScope": "3*PCS+UFSXY+2*PAS",
  "calibrationScope": "Rose1+PitchOver",
  "outputDirectory": "N:\\Project\\40.Application\\...\\Sensor_Map",
  "projectName": "BX11"
}
```

`peripheralSensorScope` 是最重要的输入，用来描述外围传感器；`calibrationScope` 用来决定保留哪些校准列；`outputDirectory` 可指定文件保存位置；`projectName` 只用于生成文件名。

调用成功后，接口返回生成路径、保留或删除的章节和校准列，以及实际解析出的传感器位置。例如返回中的 `kept_sections`、`removed_sections` 和 `sensor_selections` 可用于前端展示或问题排查。

## 输入是怎样读取的

为兼容不同调用方，接口会尝试多种字段名和嵌套位置：

- 传感器范围可使用 `peripheralSensorScope`、`peripheral_sensor_scope` 或 `Peripheral Sensor`；
- 校准范围可使用 `calibrationScope`、`calibration_scope` 或 `Calibration Scope`；
- 输出目录可使用 `outputDirectory` 或 `sensorMapOutputDirectory`；
- 如果没有直接传入输出目录，系统会根据项目 Public Link 和配置中的相对路径推导目录。

默认输出位置位于项目 Public Link 下的 `40.Application/A.Vehicle_integration/03_Sensor_map`。

生成时会读取两份配置：

| 配置 | 作用 |
|---|---|
| [PUMA_Server/config/sensormap_sections.json](../PUMA_Server/config/sensormap_sections.json) | 模板路径、章节标题、校准列、固定章节和特殊删行规则 |
| [PUMA_Server/config/sensormap_sensor_rules.json](../PUMA_Server/config/sensormap_sensor_rules.json) | 每种传感器的数量、位置、轴向和文本匹配规则 |

第一份配置定义 Excel 中有哪些章节，例如 UFS、PCS、PAS、PPS、RCS、PTS；也定义了 `ROLL_OVER`、`PITCHOVER`、`OFFZONE`、`PEDESTRIAN_PROTECTION` 等校准列。第二份配置说明不同传感器的合理安装位置，以及模板中的行该如何识别。

入口侧的请求读取逻辑在 [PUMA_Server/api/report.py](../PUMA_Server/api/report.py)，配置加载和校验逻辑在 [PUMA_Server/services/sensormap/rules.py](../PUMA_Server/services/sensormap/rules.py)。

## 传感器配置如何理解

系统会先把输入文本规范化，再逐个识别 UFS、RCS、PCS、PAS、PPS、PTS 等传感器。解析结果会包含数量、轴向、方位和层级等信息。

以 `3*PCS+UFSXY+2*PAS` 为例：

- `3*PCS` 表示 3 个 PCS；
- `UFSXY` 表示 UFS 同时需要 X、Y 两个轴；
- `2*PAS` 表示 2 个 PAS。

这一步只是在理解用户写的内容，下一步才是把数量转换成 Excel 中的具体位置。

### 数量如何映射为位置

不同传感器的安装规律不同，因此不能简单地按数量保留前几行。系统依据配置中的拓扑规则计算位置：

| 规则 | 适用传感器 | 示例 |
|---|---|---|
| 三位置 | UFS、RCS | 1 个保留 CENTRE；2 个保留 LEFT、RIGHT；3 个及以上保留 LEFT、CENTRE、RIGHT |
| 对称层级 | PCS | 2 个保留 L1、R1；3 个保留 L1、C0、R1；更多数量向外扩展对称层级 |
| 立柱成对 | PAS | 2 个保留 B 柱左右两侧；4 个保留 B、C 柱左右两侧 |
| 固定位置 | PPS、PTS | 使用规则文件中定义的固定位置 |

因此，上例通常会得到类似结果：PCS 保留 `L1`、`C0`、`R1`；UFS 保留 `LEFT`、`RIGHT` 并包含 X、Y 轴；PAS 保留 B 柱左右两侧。

当输入的 PAS 数量不能直接对应合法组合时，系统会取最接近的可用组合。UFS 和 RCS 最多保留三个位置。

语义解析在 [PUMA_Server/services/sensormap/parser.py](../PUMA_Server/services/sensormap/parser.py)，位置推导在 [PUMA_Server/services/sensormap/topology.py](../PUMA_Server/services/sensormap/topology.py)。

## Excel 是怎样裁剪的

主流程位于 [PUMA_Server/services/sensormap/service.py](../PUMA_Server/services/sensormap/service.py) 的 `generate_sensor_map()`。

因为需要保留原始 Excel 的格式和内容，系统通过 Microsoft Excel COM 编辑工作簿，而不是把表格重新写一遍。模板会先复制到本机临时目录，再由独立的 Excel 进程打开；操作结束后保存，再以原子替换的方式写入目标目录。

编辑大致按以下顺序进行：

1. 在工作表中寻找各传感器章节的标题，并确定每个章节的起止行；
2. 删除当前项目没有使用的整段传感器章节；
3. 对仍保留的章节，删除不符合计算结果的位置或轴向的行；
4. 根据校准范围删除不需要的校准列；
5. 检查应该保留的章节仍存在、应该删除的章节已消失；
6. 保存文件并清理临时文件。

例如，UFS 只选择了 LEFT、RIGHT 和 X 轴时，模板中 CENTRE 或 Y 轴对应的 UFS 行会被删除。

系统还包含一项特殊规则：如果校准范围中既没有 `ROLL_OVER` 也没有 `PITCHOVER`，会删除中央角速度传感器章节，并删除中央加速度传感器章节中与 Mid-g、Low-g 相关的行。

章节定位、行分类、删行和删列逻辑在 [PUMA_Server/services/sensormap/worksheet.py](../PUMA_Server/services/sensormap/worksheet.py)；Excel COM 生命周期和单线程保护在 [PUMA_Server/services/sensormap/excel_com.py](../PUMA_Server/services/sensormap/excel_com.py)。COM 调用会加锁，避免多个请求同时操作 Excel 进程而导致文件或进程异常。

## 文件如何保存

生成过程不会直接修改模板，也不会直接在目标目录中编辑文件：

```text
模板文件 → 本机临时副本 → Excel 编辑 → 临时输出 → 原子替换到目标目录
```

这种方式可以避免生成过程中断时留下半成品。成功后，响应会包含 `output_path` 和本次保留、删除的内容；失败时会返回具体错误信息。

## 排查时优先看哪里

| 现象 | 优先检查 |
|---|---|
| 提示配置或模板缺失 | 两个 Sensor Map 配置文件中的模板路径、章节和校准列是否完整 |
| 传感器章节保留错误 | `peripheralSensorScope` 写法，以及 `sensormap_sensor_rules.json` 中该传感器的拓扑规则 |
| 位置或轴向行删错 | 解析得到的 `sensor_selections`，以及规则文件中 `row_rules.positions`、`row_rules.axes` 的匹配文本 |
| 校准列未删或删错 | `calibrationScope` 的值和 `sensormap_sections.json` 的校准列配置 |
| Excel 无法生成或残留进程 | Windows 是否安装 Microsoft Excel；检查 COM 相关日志和临时目录权限 |
| 输出文件不在预期目录 | 请求中的 `outputDirectory`，或项目 Public Link 与相对输出路径配置 |
