### 具体代码修改

以下是按文件分类的关键代码修改对比。

#### 1. `docx/opc/constants.py` - 添加新的内容类型

**说明**：为了识别 `.docm` 文件的主文档部分，需要添加一个新的内容类型常量。

```python
# 之前 (Before)
class CONTENT_TYPE:
    # ...
    WML_DOCUMENT_MAIN = (
        "application/vnd.openxmlformats-officedocument.wordprocessingml.document.main+xml"
    )
    # ...

# 之后 (After) - 新增 WML_DOCUMENT_MACROENABLED
class CONTENT_TYPE:
    # ...
    WML_DOCUMENT_MAIN = (
        "application/vnd.openxmlformats-officedocument.wordprocessingml.document.main+xml"
    )
    WML_DOCUMENT_MACROENABLED = (
        "application/vnd.ms-word.document.macroEnabled.main+xml"
    )
    # ...
```

#### 2. `docx/package.py` - 修改包的解组和保存逻辑

**说明**：这是实现宏数据读写的核心。`Unmarshaller` 负责读取宏，`OpcPackage` 负责存储和触发保存。

##### 2.1 在 `OpcPackage` 中存储宏数据并修改 `save` 方法

**说明**：为 `OpcPackage` 类添加一个属性来暂存宏的二进制数据，并在 `save` 时将其传递给写入器。

```python
# 之前 (Before)
class OpcPackage:
    # ...
    def save(self, pkg_file: str | IO[bytes]):
        """Save this package to `pkg_file`."""
        for part in self.parts:
            part.before_marshal()
        PackageWriter.write(pkg_file, self.rels, self.parts)

# 之后 (After)
class OpcPackage:
    _vba_project_blob: bytes | None = None
    # ...
    def save(self, pkg_file: str | IO[bytes]):
        """Save this package to `pkg_file`."""
        vba_blob = getattr(self, '_vba_project_blob', None)
        
        for part in self.parts:
            part.before_marshal()
            
        PackageWriter.write(pkg_file, self.rels, self.parts, vba_project_blob=vba_blob)
```

##### 2.2 修改 `Unmarshaller` 以在读取时分离宏数据

**说明**：在解析部件列表时，如果发现是 `vbaProject.bin`，就将其二进制内容存起来，并跳过常规的 `Part` 对象创建流程。

```python
# 之前 (Before) - 逻辑上等价于
class Unmarshaller:
    # ...
    @staticmethod
    def _unmarshal_parts(pkg_reader, package, part_factory):
        parts = {}
        for partname, content_type, reltype, blob in pkg_reader.iter_sparts():
            parts[partname] = part_factory(partname, content_type, reltype, blob, package)
        return parts

# 之后 (After)
class Unmarshaller:
    # ...
    @staticmethod
    def _unmarshal_parts(pkg_reader, package, part_factory):
        parts = {}
        # 初始化
        package._vba_project_blob = None
        for partname, content_type, reltype, blob in pkg_reader.iter_sparts():
            if partname.endswith('/vbaProject.bin'): # 使用 endswith 更稳健
                package._vba_project_blob = blob
                continue
            parts[partname] = part_factory(partname, content_type, reltype, blob, package)
        return parts
```

#### 3. `docx/opc/pkgwriter.py` - 修改包的写入逻辑

**说明**：这是将宏数据实际写入文件的部分。

##### 3.1 `PackageWriter.write` 负责写入宏文件

**说明**：`write` 方法现在接收可选的 `vba_project_blob` 参数，并在所有部件写入完毕后，将宏二进制文件写入包中。

```python
# 之前 (Before)
class PackageWriter:
    @staticmethod
    def write(pkg_file, pkg_rels, parts):
        """Write a physical package (.pptx file) to `pkg_file`..."""
        phys_writer = PhysPkgWriter(pkg_file)
        PackageWriter._write_content_types_stream(phys_writer, parts)
        PackageWriter._write_pkg_rels(phys_writer, pkg_rels)
        PackageWriter._write_parts(phys_writer, parts)
        phys_writer.close()

# 之后 (After)
class PackageWriter:
    @staticmethod
    def write(pkg_file, pkg_rels, parts, vba_project_blob=None):
        """Write a physical package (.pptx file) to `pkg_file`..."""
        phys_writer = PhysPkgWriter(pkg_file)
        # 把 vba_project_blob 传给 _write_content_types_stream
        PackageWriter._write_content_types_stream(phys_writer, parts, vba_project_blob)
        PackageWriter._write_pkg_rels(phys_writer, pkg_rels)
        PackageWriter._write_parts(phys_writer, parts)

        # --- 新增逻辑：写入宏文件 ---
        if vba_project_blob:
            # 使用 PackURI 来确保路径格式正确
            from docx.opc.packuri import PackURI
            vba_partname = PackURI('/word/vbaProject.bin')
            phys_writer.write(vba_partname, vba_project_blob)
        # ---------------------------

        phys_writer.close()
```

##### 3.2 `_ContentTypesItem` 负责在 `[Content_Types].xml` 中声明宏

**说明**：`_ContentTypesItem` 在生成 `[Content_Types].xml` 文件时，需要为宏部件添加一个 `<Override>` 标签。

```python
# 之前 (Before)
class _ContentTypesItem:
    # ...
    @classmethod
    def from_parts(cls, parts):
        """Return content types XML mapping each part in `parts`..."""
        cti = cls()
        cti._defaults["rels"] = CT.OPC_RELATIONSHIPS
        cti._defaults["xml"] = CT.XML
        for part in parts:
            cti._add_content_type(part.partname, part.content_type)
        return cti

# 之后 (After)
class _ContentTypesItem:
    # ...
    @classmethod
    def from_parts(cls, parts, vba_project_blob=None):
        """Return content types XML mapping each part in `parts`..."""
        cti = cls()
        cti._defaults["rels"] = CT.OPC_RELATIONSHIPS
        cti._defaults["xml"] = CT.XML
        for part in parts:
            cti._add_content_type(part.partname, part.content_type)
        
        # --- 新增逻辑：为宏添加 Override ---
        if vba_project_blob:
            from docx.opc.packuri import PackURI
            vba_partname = PackURI('/word/vbaProject.bin')
            vba_content_type = 'application/vnd.ms-office.vbaProject'
            # 直接添加到 overrides 字典
            cti._overrides[vba_partname] = vba_content_type
        # ------------------------------------
        
        return cti
```

#### 4. `docx/api.py` 和 `docx/__init__.py` - 上层 API 的适配

**说明**：让顶层 `Document` 函数和 `PartFactory` 能够识别和正确处理 `.docm` 的内容类型。

##### `docx/api.py`
```python
# 之前 (Before)
def Document(docx: str | IO[bytes] | None = None) -> DocumentObject:
    # ...
    if document_part.content_type != CT.WML_DOCUMENT_MAIN:
        tmpl = "file '%s' is not a Word file, content type is '%s'"
        raise ValueError(tmpl % (docx, document_part.content_type))
    return document_part.document

# 之后 (After)
def Document(docx: str | IO[bytes] | None = None) -> DocumentObject:
    # ...
    if document_part.content_type not in (CT.WML_DOCUMENT_MAIN, CT.WML_DOCUMENT_MACROENABLED):
        tmpl = "file '%s' is not a Word file, content type is '%s'"
        raise ValueError(tmpl % (docx, document_part.content_type))
    return document_part.document
```

##### `docx/__init__.py`

# 之前 (Before)

PartFactory.part_type_for[CT.WML_DOCUMENT_MAIN] = DocumentPart 
# ...

# 之后 (After)
# ...
PartFactory.part_type_for[CT.WML_DOCUMENT_MAIN] = DocumentPart 
PartFactory.part_type_for[CT.WML_DOCUMENT_MACROENABLED] = DocumentPart
# ...
